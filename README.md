# Guess the Number

A responsive vanilla JavaScript guessing game with attempt tracking, keyboard support, and a persistent best score.

## Features
- Random secret number from 1–10
- Input validation
- Attempt counter
- Best score saved with `localStorage`
- Enter-key support
- Responsive interface

## Tech
HTML • CSS • JavaScript • localStorage

## Run
Open `index.html` in a modern browser.
